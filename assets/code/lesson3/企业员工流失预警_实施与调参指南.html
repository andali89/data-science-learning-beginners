4. 划分数据，再学习预处理规则

4.1 明确特征、目标和外层划分

数值或类别要结合业务含义判断，不能只看 dtype。Work_accident 虽存为整数，仍按类别处理。left 只放在 y，否则模型会直接看到答案。

from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

target_col = "left"
numeric_cols = ["satisfaction_level", "last_evaluation", "number_project",
                "average_montly_hours", "time_spend_company"]
categorical_cols = ["Work_accident", "promotion_last_5years", "sales", "salary"]
X = df.drop(columns=[target_col]).copy()
y = df[target_col].astype(int)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42
)
# 保留未经转换的外层训练集，步骤 6 的内部验证还会用到。
print("训练、测试：", X_train.shape, X_test.shape)

训练集为 11,999 条，测试集为 3,000 条。stratify=y 尽量保持离职比例；random_state=42 用于复现，不能把反复挑种子当成模型优化。比较模型时应共用同一外层划分。

4.2 数值标准化与类别编码

标准化将数值变成“偏离训练均值多少个标准差”，有利于逻辑回归、SVM、KNN 等；树模型一般不依赖标准化。下面将 Notebook 原有操作封装成函数，方便在内部验证时重新拟合，避免误用外层已处理数据。

def prepare_features(train_raw, other_raw):
    """只从 train_raw 学习规则，用同样规则转换另一个数据集。"""
    scaler = StandardScaler()
    train_scaled = train_raw.copy()
    other_scaled = other_raw.copy()
    train_scaled[numeric_cols] = scaler.fit_transform(train_raw[numeric_cols])
    other_scaled[numeric_cols] = scaler.transform(other_raw[numeric_cols])

    # 沿用 Notebook：四个类别字段均展开，保留全部类别列。
    train_ready = pd.get_dummies(
        train_scaled, columns=categorical_cols, drop_first=False)
    other_ready = pd.get_dummies(
        other_scaled, columns=categorical_cols, drop_first=False)
    # 以训练列为准；另一集合缺少的列补 0，新类别不会增加输入列。
    train_ready, other_ready = train_ready.align(
        other_ready, join="left", axis=1, fill_value=0)
    return train_ready, other_ready, scaler

X_train_ready, X_test_ready, scaler = prepare_features(X_train, X_test)
assert X_train_ready.columns.equals(X_test_ready.columns)
assert target_col not in X_train_ready.columns
print("编码后的形状：", X_train_ready.shape, X_test_ready.shape)

原数据转换后为 22 列。sales 没有大小次序，不能把部门编号当成连续数值；salary 此处也沿用独热编码。align(join="left", axis=1) 保留训练列及顺序，不要用 outer 为测试集临时扩列。训练中未出现的类别会在该字段的指示列上全部为 0，是本例的简化处理，不代表模型学会了新类别。

检查点：先分后拟合；数值字段与类别字段互斥；两个输入列完全一致。替换缩放器、修改 drop_first 或字段列表后，必须重跑预处理和模型。drop_first=True 可去除每组的冗余列，但会改变系数解释基准；dummy_na=True 可增加缺失类别列，不能代替缺失情况调查。

5. 理解并运行两个示例模型

fit(X, y) 学习模型；predict(X) 返回类别。先理解两种模型，再根据自己的选择实现第三种模型。以下先建立默认配置的基线，最终配置应在步骤 6 的验证后确定。

from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score, classification_report

logit = LogisticRegression(max_iter=1000)
rf = RandomForestClassifier(
    n_estimators=300, random_state=42,
    class_weight="balanced", n_jobs=-1
)
models = {"逻辑回归": logit, "随机森林": rf}
for name, model in models.items():
    model.fit(X_train_ready, y_train)
    # 此处用训练集检查拟合是否完成，最终测试评价放在步骤 7。
    train_pred = model.predict(X_train_ready)
    print(name, "训练准确率：", accuracy_score(y_train, train_pred))

逻辑回归适合作为容易解释的基线；随机森林通过多棵树学习非线性关系。训练分数高并不等于新数据表现好，更不能据此判断哪个模型更好。

模型 关键参数 含义与可比较设置
逻辑回归 C 正则强度的倒数，越小约束越强；可比较 0.1、1、10
逻辑回归 max_iter、solver 迭代上限与求解器；有收敛警告时检查缩放，再提高上限
逻辑回归 class_weight None、"balanced" 或类别权重字典；改变损失权重，不增加样本
逻辑回归 正则类型 L1/L2/elastic net 与求解器需兼容；L1 可使用 saga，elastic net 还需设置混合比例；按所安装版本 API 配置
随机森林 n_estimators 树数量，原示例 300；可比较 100/300/500，同时记录耗时
随机森林 max_depth 最大深度，None 不设上限；限制深度可能缓解过拟合
随机森林 min_samples_leaf、min_samples_split 限制叶节点及继续分裂所需样本数，增大可使模型更平滑
随机森林 max_features 每次分裂考虑的特征数，如 "sqrt"、0.8
随机森林 class_weight 调整类别权重，效果需验证，不保证召回率提高

6. 设计参数实验：只用训练集内部验证

正确流程是“外层训练集 → 内部训练/验证 → 选择配置 → 完整外层训练集重新拟合 → 最终测试”。不要把测试集作为反复试参数的评分表，也不要先标准化整个外层训练集再划分内部验证。

# 在未经转换的外层训练数据中分出验证部分，测试集保持不动。
X_inner, X_valid, y_inner, y_valid = train_test_split(
    X_train, y_train, test_size=0.2, stratify=y_train, random_state=42
)
X_inner_ready, X_valid_ready, inner_scaler = prepare_features(X_inner, X_valid)
# 接下来由学生创建候选模型：fit 只接收内部训练集，predict 接收验证集。

选择一个参数，每次只改它，其他条件固定。记录至少两个候选设置，比较离职类 Precision、Recall、F1，必要时结合验证混淆矩阵和耗时。可以用 classification_report(y_valid, valid_pred, output_dict=True) 提取 "1" 对应指标。自行完成循环或逐次运行，不需要先学复杂搜索程序。

待填写记录 内容
实验对象 模型、参数名、候选值
固定条件 字段、划分、随机种子、其他参数
验证表现 各候选的离职类 Precision、Recall、F1；可补充 AUC、耗时
选择依据 提高识别率是否带来更多误报，HR 是否有能力跟进
最终评价 确定配置，完整训练集重新拟合后的测试指标

选定配置后，将参数写回 models 中的对应模型，在 X_train_ready, y_train 上重新 fit。不同种子或测试比例的稳健性分析须单独报告，不能按测试分数挑最有利划分。若尝试交叉验证，缩放、填补等应放进 Pipeline，在每折训练部分重新拟合；这是选做内容。

阈值也是选择：降低离职概率阈值通常增加预警人数，同时改变误报与漏报。阈值也必须在验证数据上确定；SVM 决策分数不等于概率，不能直接套用概率阈值 0.5。

7. 最终评价：看懂指标与图表

确定参数、完成三模型训练后，统一评价保留的测试集。下面代码演示类别指标及混淆矩阵；将你自己的第三种模型加入 models 后再运行。

from sklearn.metrics import confusion_matrix, ConfusionMatrixDisplay

rows = []
for name, model in models.items():
    pred = model.predict(X_test_ready)
    report = classification_report(
        y_test, pred, output_dict=True, zero_division=0)
    rows.append({
        "模型": name,
        "Accuracy": accuracy_score(y_test, pred),
        "Precision(1)": report["1"]["precision"],
        "Recall(1)": report["1"]["recall"],
        "F1(1)": report["1"]["f1-score"],
    })
    cm = confusion_matrix(y_test, pred, labels=[0, 1])
    ConfusionMatrixDisplay(cm, display_labels=["留任", "离职"]).plot(
        cmap="Blues", values_format="d")
    plt.title(name + "：测试集混淆矩阵")
    plt.show()
results_df = pd.DataFrame(rows)
print(results_df)
# 学生补充：每个模型的连续分数、ROC 曲线和 AUC 列。
指标 含义 解读重点
Accuracy 全部预测中正确的比例 多数类可能掩盖离职漏报
Precision TP / (TP + FP) 被预警者中实际离职的比例，联系跟进成本
Recall TP / (TP + FN) 实际离职者被识别的比例，联系漏报风险
F1 Precision 与 Recall 的调和平均 兼顾两者，不等于业务收益
ROC AUC 跨阈值的排序区分能力 不是分类准确率或个人离职概率

混淆矩阵行是真实类别、列是预测类别，按 [0,1] 排列时为 [[TN, FP], [FN, TP]]。FP 是留任者被误报，FN 是实际离职者被漏报。zero_division=0 在分母为零时按 0 输出，应同时检查是否完全没有预测出离职者。

8. 解释特征与业务含义

树模型重要性与转换后的列对应，不是原始九个字段；独热编码会将一个字段的贡献分散到多个列。以下沿用随机森林示例，查看前十项。

rf = models["随机森林"]  # 取最终配置的已拟合对象，避免仍解释旧模型。
logit = models["逻辑回归"]
importance = pd.Series(rf.feature_importances_, index=X_train_ready.columns)
top10 = importance.sort_values(ascending=False).head(10)
plt.figure(figsize=(8, 5))
sns.barplot(x=top10.values, y=top10.index)
plt.title("随机森林：前十项特征重要性")
plt.xlabel("不纯度下降贡献（没有正负方向）")
plt.tight_layout()
plt.show()

# 系数保留正负号，再按绝对值排序，不能排序后丢掉方向。
coef = pd.Series(logit.coef_[0], index=X_train_ready.columns)
print(coef.loc[coef.abs().sort_values(ascending=False).head(10).index])

逻辑回归中，在其他输入不变时，正系数与更高预测离职倾向相关，负系数相反。数值字段已标准化，系数对应一个标准差变化。保留全部独热列且使用正则化时，不应将单个类别系数直接说成“相对某基准类别的效应”。

随机森林重要性非负，不表示作用方向；相关特征和字段类型也会影响排名。两种权重都不是显著性检验，不证明因果关系。建议按“证据—解释—建议—待调查信息”撰写，例如先核对工时与岗位分布，再考虑工作安排的调查或试点，不能直接断言某项干预必然减少离职。

NameError 是否跳过上游单元，或重启内核后未重新运行
列名或输入维度不一致 是否以训练列对齐，第三种模型是否复用相同输入
收敛警告 数值标准化、异常值、参数设置，再考虑增大迭代上限
中文显示方框 使用本机已安装中文字体，主题设置后再设字体
准确率高但预警效果差 查看标签 1 的 Recall、F1 及 FN，不只看总体平均

选做扩展可包括图表尺寸/配色调整、classification_report(output_dict=True) 汇总、使用 time.perf_counter() 记录耗时或 Pipeline 交叉验证。SMOTE 仅在训练部分重采样，交叉验证时须在折内完成；含类别特征时需研究方法适用性，不应直接插值全部独热列。更换目标列属于新任务，不能替代本实验的 left 预测。
