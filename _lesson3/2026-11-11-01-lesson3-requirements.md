企业希望根据员工满意度、工作安排、薪资等级等信息识别离职风险。本实验以 `HR_comma_sep.csv` 为数据，完成二分类建模，并用自己的运行证据提出管理建议。实验为**综合型、必做、每人独立完成，共 4 学时**。

## 一、实验目的

- 掌握读取、检查、探索、预处理、分类建模、验证与解释的完整流程，说明每一步的作用。
- 理解特征 `X`、目标 `y`、训练集、验证数据和测试集的分工。
- 独立比较至少三种不同分类模型，用离职类指标评价预警效果。
- 区分预测关联与因果关系，将模型证据转化为有依据的管理建议。

## 二、实验环境

- Windows 10 或以上；Python 3.9+，新建环境建议使用 Python 3.10+；已有 3.9 环境须安装兼容库版本。
- Jupyter Notebook 或 PyCharm；依赖 pandas、numpy、scikit-learn、matplotlib、seaborn。
- 将 `hr_notebook.ipynb` 和 `HR_comma_sep.csv` 放在同一工作目录，记录 Python 与主要库版本。

## 三、实验原理与方法

一行是一条员工记录。目标 `left=1` 表示离职，是本实验的**正类**；`left=0` 表示留任。`left` 不得进入特征。逻辑回归学习线性分类关系，随机森林可表达非线性关系；第三种模型由学生自行选择与实现。

训练集学习参数；训练集内部的验证数据用于选择超参数；测试集评价已确定的方案。**先划分数据，再在对应训练部分拟合标准化等规则**，验证和测试只能使用已有规则，避免数据泄漏。

| 字段 | 中文含义与处理 |
| --- | --- |
| `satisfaction_level` | 满意度，数值特征 |
| `last_evaluation` | 最近一次绩效评价，数值特征 |
| `number_project` | 项目数量，数值特征 |
| `average_montly_hours` | 平均月工时，数值特征；保留原拼写 `montly` |
| `time_spend_company` | 在公司工作的年数，数值特征 |
| `Work_accident` | 是否发生工伤，0/1 类别 |
| `promotion_last_5years` | 过去五年是否晋升，0/1 类别 |
| `sales` | 所属部门，不是销售额 |
| `salary` | 薪资等级 low/medium/high，不是工资金额 |
| `left` | 离职标签，目标变量 |

## 四、实验内容与步骤

### 步骤 1：读取与初步检查

检查表头、字段类型、样本量、缺失值、重复记录和异常取值。当前文件为 14,999 行、10 列，无缺失，存在 3,008 条完全重复记录（按保留首条统计）。不能据此断言它们就是同一员工：数据没有员工标识。与示例比较时保留原数据并记录问题；若另行删除，说明理由、样本变化及对划分和评价的影响。

### 步骤 2：探索性数据分析（Exploratory Data Analysis，EDA）

统计离职比例，观察类别不平衡；至少选择一个数值特征和一个类别特征，通过直方图、箱线图、频数或分组比例分析。说明图表回答的问题、主要观察与证据。部门人数不同，离职人数与离职率不能混为一谈。

### 步骤 3：确定特征与处理方案

分离 `X` 和 `y`，确定五个数值字段和四个类别字段，说明缺失处理与编码方案。当前数据无缺失，不需要机械填补或删除。需要学习的填补值只能由训练部分估计。

### 步骤 4：划分数据

统一使用外层 80%/20% 分层划分，`random_state=42`、`stratify=y`。原数据对应训练集 11,999 条、测试集 3,000 条。`stratify` 保持原有类别比例，不是使两类各占一半。

### 步骤 5：标准化与类别编码

对训练集五个数值字段调用 `StandardScaler.fit_transform`，对测试集调用同一对象的 `transform`。四个类别字段按 Notebook 独热编码，保留全部类别列；以训练列为准对齐输入顺序。验证集实验同样遵守“内部训练部分拟合、验证部分转换”。

### 步骤 6：模型训练与验证

在示例逻辑回归和随机森林之外，自行增加至少一种分类器，合计至少三种不同模型。记录模型名称、参数及选择理由。选择一个超参数开展候选值比较，固定其他条件，在训练集内部验证后确定配置，再重新拟合外层完整训练集。不要反复按测试成绩选择参数。

### 步骤 7：模型评估与可视化

汇总三种模型的 Accuracy、离职类 Precision、Recall、F1 和 ROC AUC；绘制并解读混淆矩阵与 ROC 曲线。ROC 使用连续概率或决策分数，不使用预测类别。讨论误报、漏报和 HR 跟进成本；不以必须达到某一准确率作为完成标准。

### 步骤 8：特征影响分析

展示模型系数或树重要性排序图，解释主要特征。数值系数对应标准化后的变化，类别系数受编码方式影响；树重要性没有正负方向。结合探索分析讨论关联，不把模型权重当作因果效应或显著性检验。

建议四学时依次完成：数据认识与探索；预处理与基线；扩展模型与验证；解释与报告。交叉验证、SMOTE、额外算法为选做。

## 五、实验结果

将自己的运行结果填入报告第五部分，至少包含：

- 数据规模、类型、缺失与重复检查，数值及类别特征的探索图表与结论。
- 预处理方法、数据划分设置、三种模型及参数说明。
- 三模型指标对比表、混淆矩阵、ROC 曲线与 AUC，重点解释离职类表现。
- 参数实验记录：候选值、固定条件、验证指标、选择理由和最终测试结果。
- 特征影响图或系数表，说明解释边界。

## 六、实验意义及讨论

### （1）主要结论总结

分别概括探索性数据分析、模型评价及特征分析发现。每个结论应对应实际图表或指标，不能直接照抄示例成绩。

### （2）启示与对策

按“结果证据 → 可能解释 → 管理建议 → 待验证信息”提出具体建议。例如先调查岗位与工时安排，再考虑干预试点；不能仅凭关联断言减少工时必然降低离职率。

### （3）不足与展望

讨论过拟合、重复记录、数据缺少员工标识及时间轨迹、模型解释局限，并提出可验证的改进方向。
